# MouseHunt Userscripts

A collection of custom Tampermonkey userscripts and browser tools for [MouseHunt](https://www.mousehuntgame.com/), maintained by **[mouseindustry](https://greasyfork.org/en/users/735492-mouseindustry)**.

## Installation

Install [Tampermonkey](https://www.tampermonkey.net/), then install any script from its Greasy Fork page.

## Updates

The scripts are maintained on GitHub and synchronized with Greasy Fork through GitHub webhooks.
